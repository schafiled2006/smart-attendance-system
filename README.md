# سامانه هوشمند حضور و غیاب با تشخیص چهره (Smart Attendance System)

این پروژه یک سیستم حضور و غیاب کلاسی هوشمند، **کاملاً آفلاین** و سبک بر پایه پردازش تصویر و هوش مصنوعی است که بدون نیاز به اینترنت و بدون نیاز به کارت گرافیک (فقط با پردازنده معمولی یا CPU) کار می‌کند.

سیستم دارای دو بخش اصلی است:
1. **بک‌اند (Backend):** ساخته‌شده با Python 3.11، فریم‌ورک FastAPI، کتابخانه‌های بینایی ماشین OpenCV و `face_recognition` (مدل HOG)، دیتابیس SQLite و ماژول خروجی اکسل راست‌به‌چپ با تقویم شمسی.
2. **فرانت‌اند (Frontend):** رابط کاربری وب مدرن، کامپوننت‌محور و واکنش‌گرا (RTL) با React 18، Vite و Tailwind CSS به زبان فارسی همراه با داشبورد مدیریتی، لیست کلاس و استریم آنلاین وب‌کم.

---

## ویژگی‌های کلیدی سامانه

- **۱۰۰٪ آفلاین و محلی:** هیچ داده، چهره یا کدی به اینترنت یا سرورهای ابری ارسال نمی‌شود؛ امنیت کامل و حفظ حریم خصوصی.
- **پردازش روی CPU:** نیازی به کارت گرافیک مجزا یا درایورهای سنگین CUDA نیست؛ با مدل سریع HOG روی هر لپ‌تاپ معمولی دانشگاهی اجرا می‌شود.
- **قانون ضد تقلب فریم پیوسته:** برای جلوگیری از ثبت اشتباه یا عبور اتفاقی، چهره باید حداقل در ۳ فریم متوالی در دید دوربین پایدار بماند تا حضور قطعی ثبت گردد.
- **ثبت هوشمند وضعیت ورود:** تفکیک خودکار دانشجویان به **حاضر**، **تأخیر** (بر اساس سقف دقایق مجاز تعریف‌شده برای جلسه) و **غایب**.
- **امکان مدیریت دستی:** ثبت دستی حضور یا حذف وضعیت برای مواقع خاص یا عدم همراه داشتن چهره.
- **گزارش‌گیری رسمی اکسل (Excel):** صدور فایل اکسل استاندارد، کاملاً راست‌به‌چپ (RTL)، با تاریخ و ساعت شمسی دقیق، اسامی و شماره‌های دانشجویی تفکیک‌شده.
- **دوگانه وب و خط فرمان (CLI):** قابلیت مدیریت کامل هم از طریق پنل وب و هم از طریق ترمینال با اسکریپت `manage.py`.

## پیش‌نیازهای سیستمی

قبل از شروع، مطمئن شوید نرم‌افزارهای زیر روی سیستم (ویندوز) نصب هستند:

1. **پایتون (Python 3.11 نسخه ۶۴ بیتی):** هنگام نصب پایتون حتماً تیک گزینه `Add Python to PATH` را بزنید.
2. **نود جی‌اس (Node.js نسخه ۱۸ یا بالاتر):** برای اجرای رابط کاربری فرانت‌اند ([دانلود از وب‌سایت رسمی](https://nodejs.org)).
3. **وب‌کم:** وب‌کم داخلی لپ‌تاپ یا اتصال گوشی هوشمند به عنوان وب‌کم با نرم‌افزارهایی مثل **Iriun Webcam** یا **DroidCam** از طریق کابل USB یا وای‌فای مشترک.

## راهنمای قدم‌به‌قدم اجرای سامانه (از صفر تا صد)

### قدم ۱: فعال‌سازی محیط مجازی پایتون (Virtualenv)

یک پنجره ترمینال PowerShell در پوشه اصلی پروژه باز کنید و دستورات زیر را وارد نمایید:

```powershell
# ساخت محیط مجازی (تنها یک‌بار انجام می‌شود)
py -3.11 -m venv venv

# فعال‌سازی محیط مجازی
venv\Scripts\activate
```

> **نکته:** هر بار که ترمینال جدیدی باز می‌کنید، باید دستور `venv\Scripts\activate` را اجرا کنید تا عبارت `(venv)` در ابتدای خط فرمان ظاهر شود.

---

### قدم ۲: نصب کتابخانه‌های بک‌اند

دستورات زیر را داخل محیط فعال `(venv)` اجرا کنید:

```powershell
# نصب وابستگی‌های پروژه
pip install -r requirements.txt

# نصب کتابخانه تشخیص چهره بدون تداخل دپندنسی‌ها
pip install face_recognition --no-deps
```

> **بررسی صحت نصب:** برای اطمینان از سلامت نصب و کتابخانه‌ها، می‌توانید دستور زیر را اجرا کنید:
> ```powershell
> python check_env.py
> ```
> تمام ماژول‌ها و تست‌های محلی باید در خروجی عبارت `[OK]` نمایش دهند.

---

### قدم ۳: آماده‌سازی دیتابیس و ثبت چهره دانشجویان

#### الف) ایجاد دیتابیس اولیه
اگر برای اولین بار پروژه را راه‌اندازی می‌کنید، دستور زیر دیتابیس SQLite را در پوشه `data/` می‌سازد:

```powershell
python manage.py init-db
```

#### ب) افزودن عکس دانشجویان و آموزش چهره‌ها
برای آموزش چهره هر دانشجو:
1. در پوشه `known_faces/` یک پوشه با **شماره دانشجویی** فرد بسازید (مثلاً `known_faces/04111033302502`).
2. حداقل ۳ و حداکثر ۵ عکس باکیفیت و واضح از زوایای مختلف چهره او (فرمت JPG یا PNG) داخل پوشه قرار دهید.
3. با دستور زیر، دانشجو را معرفی و عکس‌های او را به وکتورهای ریاضی (امبدینگ ۱۲۸ بعدی) تبدیل کنید:

```powershell
# تعریف مشخصات دانشجو
python manage.py add-student --id 04111033302502 --name "میکاییل دهقانی سانیج" --major "مهندسی کامپیوتر" --term "ترم ۳"

# استخراج ویژگی‌ها و آموزش چهره‌ها
python manage.py process-photos --id 04111033302502
```

> برای مشاهده فهرست دانشجویان ثبت‌شده و وضعیت امبدینگ آن‌ها:
> ```powershell
> python manage.py list-students --compact
> ```

---

### قدم ۴: اجرای سرور بک‌اند (Backend Server)

برای روشن کردن موتور پردازشی و API بک‌اند، دستور زیر را اجرا کنید:

```powershell
python manage.py run
```

با این کار، سرور روی آدرس `http://127.0.0.1:8000` روشن می‌شود.
- برای دیدن مستندات تعاملی Swagger API می‌توانید به نشانی `http://127.0.0.1:8000/docs` مراجعه کنید.

---

### قدم ۵: اجرای رابط کاربری فرانت‌اند (Frontend Dashboard)

یک پنجره **جدید** در PowerShell باز کنید و دستورات زیر را برای اجرای وب‌سایت وارد کنید:

```powershell
# ورود به پوشه فرانت‌اند
cd frontend

# نصب وابستگی‌های فرانت‌اند (تنها یک‌بار انجام می‌شود)
npm install

# اجرای برنامه در حالت توسعه
npm run dev
```

حالا مرورگر خود را باز کنید و وارد آدرس زیر شوید:
👉 **[http://localhost:5173](http://localhost:5173)**

## نحوه کار با سامانه در زمان برگزاری کلاس

1. **ورود به داشبورد:**
   - پس از باز کردن `http://localhost:5173`، وضعیت اتصال سرور بک‌اند (دایره سبز رنگ در بالا سمت چپ) نمایش داده می‌شود.
2. **شروع جلسه کلاسی:**
   - از نوار کناری وارد بخش **«جلسات کلاسی»** شوید.
   - روی دکمه **«شروع جلسه جدید»** کلیک کنید و مهلت تأخیر را تعیین کنید (پیش‌فرض: ۱۰ دقیقه).
3. **فعال‌سازی دوربین و تشخیص چهره:**
   - به تب **«کلاس زنده و تشخیص»** بروید.
   - از منوی پایین صفحه، وب‌کم لپ‌تاپ یا دوربین متصل به گوشی (مانند *Iriun Webcam*) را انتخاب نمایید.
   - به محض قرار گرفتن هر دانشجو روبه‌روی لنز دوربین:
     - کادر زرد/کهربایی نشان‌دهنده اسکن چهره در فریم‌های پیوسته است.
     - پس از تثبیت در ۳ فریم متوالی، کادر سبز شده و با صدای اعلان کوتاه، وضعیت حضور فرد فوراً ثبت و در لیست کلاسی تیک می‌خورد.
     - در صورت چهره ناشناس یا ثبت‌نشده، کادر قرمز با برچسب «ناشناس» نمایش داده می‌شود.
4. **ثبت دستی (در صورت لزوم):**
   - در ستون سمت چپ، استاد می‌تواند در هر لحظه حضور دانشجویی را به صورت دستی ثبت کند یا وضعیت را تغییر دهد.
5. **پایان جلسه و صدور گزارش اکسل:**
   - پس از پایان زمان کلاس، با کلیک بر روی دکمه **«بستن جلسه»** جلسه خاتمه می‌یابد.
   - از بخش **«گزارش‌های اکسل»**، می‌توانید فایل گزارش خروجی همان جلسه را با یک کلیک دانلود کنید.
   - فایل اکسل مستقیماً در پوشه `reports/` ذخیره شده و دارای جدول راست‌به‌چپ با تاریخ و ساعت دقیق شمسی، مشخصات دانشجویان و وضعیت حضور/تأخیر/غیبت هر دانشجو است.

## راهنمای دستورات خط فرمان (CLI Reference)

برای کاربرانی که ترجیح می‌دهند بدون استفاده از مرورگر وب کارهای مدیریتی را انجام دهند، ابزار `manage.py` در ریشه پروژه قرار دارد:

| دستور | توضیح |
| :--- | :--- |
| `python manage.py init-db` | ایجاد جداول دیتابیس و درس پیش‌فرض |
| `python manage.py add-student --id <ID> --name "<NAME>"` | افزودن مشخصات دانشجو |
| `python manage.py process-photos --id <ID>` | پردازش عکس‌ها و ایجاد بردار امبدینگ برای یک دانشجو |
| `python manage.py process-photos` | پردازش عکس‌ها برای تمامی دانشجویانی که امبدینگ ندارند |
| `python manage.py list-students` | نمایش فهرست کامل دانشجویان همراه با جزییات |
| `python manage.py start-session [--late-after 10]` | آغاز یک جلسه کلاسی جدید |
| `python manage.py status` | مشاهده وضعیت جلسه فعال و آمار کلاس |
| `python manage.py close-session` | بستن جلسه کلاسی جاری |
| `python manage.py report [--session-id <ID>]` | تولید و ذخیره گزارش اکسل فارسی در پوشه `reports/` |
| `python manage.py run` | راه‌اندازی سرور بک‌اند |
| `python main_test.py` | تست پنجره‌ای دوربین و تشخیص چهره مستقیم در OpenCV |

## نکات مهم و رفع عیب‌های رایج

- **نور و زاویه دوربین:** الگوریتم HOG بسیار سریع و سبک است؛ با این حال اطمینان حاصل کنید که چهره در معرض نور کافی قرار دارد و از تابش مستقیم نور شدید از پشت سر به لنز دوربین خودداری شود.
- **تغییر دوربین:** اگر تصویر دوربین در مرورگر لود نشد، دسترسی مرورگر (Permission) به وب‌کم را بررسی کنید یا از منوی انتخاب دوربین در پایین صفحه استریم زنده، دستگاه دیگری را برگزینید.
- **استفاده از گوشی به عنوان دوربین:** نرم‌افزار رایگان *Iriun Webcam* را روی گوشی و ویندوز نصب کرده و هر دو را به یک مودم یا کابل USB متصل کنید؛ در فرانت‌اند نام *Iriun Webcam* در فهرست دوربین‌ها پدیدار خواهد شد.
